## Agent skills

### Issue tracker

Track issues and specs in GitHub Issues; before ticket operations, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage labels; before classifying issues, read `docs/agents/triage-labels.md`.

### Domain docs

探索代码、调整概念或核验接口前，阅读 [领域文档导航](docs/agents/domain.md)，确认当前设计、共享术语与现存实现的边界。

### 模块设计方案

编写、修订或核验已选定模块的设计与接口闭合时，使用 [module-design](.agents/skills/module-design/SKILL.md)。

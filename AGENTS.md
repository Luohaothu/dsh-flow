## Agent skills

### Issue tracker

Track issues and specs in GitHub Issues; before ticket operations, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage labels; before classifying issues, read `docs/agents/triage-labels.md`.

### Domain docs

Use a single-context layout; before exploring the codebase, read `docs/agents/domain.md`.

### 模块设计方案

为已选定的模块编写设计或重构方案时，使用 [module-design](.agents/skills/module-design/SKILL.md)，按用户指定的语言、章节和范围交付；默认采用专业中文和五部分结构。

## 对照、观察器与界面边界

M01 D/D 是一次普通主会话身份配置对照，复用原输入和冻结判据，产品包、SDK、技能及观察器身份一致，只改变主会话匿名身份。执行后补记曾误标为预执行说明，已移出并恢复原预登记字节；补记只是追溯，不能充当预登记或评分规则。原 B/D 失败保留，单次对照不用于模型排行、因果结论或稳定性泛化。

N09 保留原 `OBSERVING`：已结束的辅助请求仍被观察器标为 running，阻碍自然收敛；真实最终业务产物已存在，可独立判失败。第26次请求缺少结束标记和 usage，未知用量不补零。M05 v10 因无进展中止；其待办作业没有正式提交，空终态集合上的 readback 标志不能证明真实读回。M13 v11 两次均为 `ABORTED`：01 在已报告用量判界收尾，02 按无进展判界收尾；02的最后工具反馈机会被判界截断与调用本身确实不合格并存，不能抹去任何一项。其余六次已关闭记录达到 `SETTLED`。上述十次及 v12 均退出130且未强制终止，拥有者收尾不自动算业务或观察器失败。v12 的原始观察状态仍为 `ABORTED/no-progress`；独立复核区分观察器取消确认假阴性和实际最终交付，不改写原始状态。

D/D 对照错过 UI 保留窗口，未取得团队/全局页面和返回原会话导航，不能用后端快照补 UI。M01 B/D 的原生任务条尚有进行中项，属于 Agent 维护状态，不能直接判作渲染故障。M04、M05 v11、M08 仅通过实际观察的 Web 基本状态与导航。M08 二轮待办仅有 AX 证据，名为 inflight 的截图实际上已经两份 submitted、各提交一次；最终已释放且清理完成，不能按文件名推状态。M13 v11-01 可见补充排队后实际消费、三份作业状态为 cancelled/submitted/submitted、零待办缓存及返回 Main 的历史，仍无最终答复；停止后断连不据此判产品崩溃。v11-02 只有未闭环页面和排队证据，不补“已消费”。v12 实际界面已见 Main/root idle、零待办及 `cancelled/submitted` 最终状态，但没有有效 `ui-ack`，产物预览未完成，Web 的无法读取主机桌面信息提示保留。完整 U01–U08、主题、断点、键盘、动画、只读及其他宿主仍未完成。原始截图不公开。

团队根计一个 Flow 节点，宿主原生辅助不自动成为 Flow 成员。N09 和 M13 v11-01 各有一个原生辅助，Flow 仍为单根；其余单根运行也不能按工具、模块或 todo 数量扩充规模。当前有效 Flow 贡献规模为0、1或 M04 的4；M13 v11-02 的初始化根不计有效贡献。更大规模、群聊/黑板和各目标模板采用均未核销。G06 的 v12 补充传播、正式新任务、取消、最新读回及最终答复成立；监控更新的完整业务整合仍不完整，因此完整G06不通过，其他事件不推定。v12 只有1个有效Flow根、0子成员、0原生辅助、0群和0黑板写入，模式查询/采用均为0。

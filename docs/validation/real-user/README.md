`pnpm typecheck`、`pnpm build`、`pnpm docs:build`、`pnpm test:native-api` 和 `pnpm test:inventory` 均通过，inventory 为 8 项。`pnpm test` 在允许启动 Chrome 的环境中为 711 项通过，0 失败、0 跳过。

## 取证边界

`tests/natural/host.mjs` 使用与 DSH 界面相同的正式会话及技能入口。它只记录实际请求、会话、作业与快照，不注册额外模型工具，不改写团队职责或筛选模型可见工具。`SETTLED` 表示观察达到稳定边界，业务与自主能力仍需独立评分。

输入渠道按各轮真实证据登记，正式技能 API 与实际 GUI 发送分别统计。观察器状态或渠道标记不能单独代替 GUI 操作证据。

已有 `tests/live` 的受控命令及工具序列保留为辅助诊断入口，其结果不计入自主主线。公开记录不包含原始服务身份、端点、账号、接入配置、原始模型输出或未脱敏截图。

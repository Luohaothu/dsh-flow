## 探索与最终留出的边界

读取边界审计确认，当前锁定 SDK 的 `workspace-write` 约束写入，不隔离候选对工作目录外原本可读文件的读取。专用 home、全新工作目录和 `private` 命名均不能单独证明参考答案不可读。此结论不表示已证实某轮实际读取答案；本批记录按探索结果解释。

最终留出还须使用新材料，在候选运行期间仅保留参考答案及评分材料的密文，并使解密密钥处于候选不可访问的环境；全部候选及后代停止、输出与轨迹封存后，才可在独立评估上下文解密评分。协议及相应证据尚未完成，不能称盲验已实现；已揭盲的探索材料也不能充当独立最终留出。

这些记录来自多个探索版本，成功率按版本和场景分别核验。模式、G01–G07、有效规模与最终连续三次留出目标尚未在本稿核销。

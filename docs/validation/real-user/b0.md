## 早期记录与环境修正

共保留九个启动目录、八份完整 evidence 和 23 条已记录请求。

- 初次空 `DSH_HOME` 仍发现 221 项用户全局技能。后续使用宿主支持的 `DSH_AGENTS_HOME` 指向空目录，并从真实会话记录核对没有全局技能混入。
- 首轮为保护评分目录使用外层系统沙箱，导致 DSH 自身 shell 沙箱无法启动。后续运行恢复宿主正常的工作区写入权限路径。评分答案和检查器在被测进程启动前加密移出，解密密钥不进入被测进程或业务目录。
- 一次重叠启动因端口占用退出，没有模型请求。后续按顺序完成进程收尾。
- 模型 C 的一次请求因不支持所选推理设置被拒绝。按服务实际能力修正配置后重新完成校准。失败保留，缺失用量保持未知。

接入参数和实际服务信息只留在本地。早期受干扰轮次不计作干净环境校准通过。

## 采集与收尾核验

新增[观察器](../../../tests/natural/README.md)保留正式工具和系统提示，记录实际会话、作业、请求、用量与展示快照。`SETTLED` 表示观察边界稳定，评分者仍须读取真实工具结果和交付。

独立审查指出聊天心跳会重置无进展计时，以及流式 `finish` 错误可能被误标为成功请求。当前采集器已修正。另修正 runner 在主进程退出、后代继续持有输出管道时的收尾，使用本轮进程组和有界管道等待。

`node --test tests/natural/runner.test.mjs` 的两项真实进程回归通过，验证正常收尾和持有输出管道的后代清理。两个入口的 `node --check` 与公开文件隐私扫描均通过。

工程基线检查结果见[执行记录](README.md#基线工程检查)。自主 N/M/G 场景、完整界面矩阵、匹配 Desktop 及留出验收继续在后续批次执行。

# Auditor 三场景消融实验：执行前协议

本协议在正式模型运行前冻结。研究问题是：在相同交付、证据和模型条件下，增加独立 Auditor 能否减少 Orchestrator 的不充分验收，且收益是否超过追加一次自审？当前生产实现要求审核才接受，不作为“Auditor 必要”的实验证据。实验不修改该门禁。

## 假设、对照与可判定范围

H1：独立 Auditor 降低初验错误放行。H2：独立审核的效果优于等额追加的 Orchestrator 自审。H3：收益不能靠一律拒绝解释，合格误拦与成本必须同时报告。零假设为本样本中看不到额外质量收益。

每个单元固定一个 Worker 交付快照，由真实本地模型 Orchestrator 初验形成记录。A 使用初验结果；B 恢复同一个 Orchestrator 会话追加业务复核；C 新建 Auditor 会话，审核该初验记录及其实际观察。C 放行必须同时满足 A 业务验收通过和 Auditor 合规审核通过。Auditor 不补做业务验收、不直接要求 Worker 返工。本轮不测量修复后的最终业务交付。

B 和 C 使用同一不可变材料和初验记录、同一服务与模型、每请求 2048 输出 token 上限及每阶段 6 次工具/120 秒上限，执行顺序按重复次数交换。原生角色提示来自 `core/briefing.ts`；B 保留自身上下文，C 获得初验记录但不继承原会话，因此比较的是“独立角色＋独立上下文”的整体效果，不能拆分两者的单独贡献。真实消耗按原生请求、成功 assistant message 的 token 和时间报告，不把相同上限说成实际消耗完全相同。

模型只能使用读取冻结包与提交实验决定的工具。包含正式标准、当前 result_ref、产物和实际捕获观察；C 额外看到 A 验收与 native read call IDs。读取材料不等价于执行材料中描述的测试。实验工具不产生生产 `ACCEPTED`，也不自动代批 `flow_audit`。实验单独使用 profile、会话、数据库和工作区，保持用户当前界面实例。

## 三个实验及评分标准

| 实验 | 交付与业务标准 | 独立 oracle | 三类缺陷 |
| --- | --- | --- | --- |
| 代码开发 | JavaScript `dedupeLatest`：数值版本比较、负版本、平局取最后记录、首次 ID 顺序、空输入 | 执行完整边界矩阵，并核对测试回执的源码 hash | 负数边界未覆盖；旧正确代码的回执用于当前字典序比较代码；平局实际失败仍可能被接受 |
| 深度调研 | 冻结四篇 SQLite 官方材料，整合六项事务/并发/隔离事实与条件 | 结构化事实、引用出处和字面摘录匹配；核对当前 result_ref | 遗漏未提交读取的条件；旧结果来源检查；声称 WAL 多写者并发且伪造引用 |
| 数学证明 | 对所有整数证明 `6` 整除 `n^3-n` | 精确因式分解与完整模 2/模 3 剩余类；反例验证错误引理；检查量词与版本 | 用 100 个正整数样例替代全称证明；旧正整数命题验证；错误声称 `n(n+1)` 总被 6 整除 |

每个场景另有一份完整合格交付。共 3 场景 × 4 类交付 × 2 次重复 = 24 个配对单元，72 个原生阶段。pilot 只检查接口，不计正式结果；必须先得到三阶段均完整的 pilot 配对再启动正式轮。隐藏 oracle 不进入模型输入；正式运行前写入清单、输入/代码/协议 SHA256，执行后检查漂移，原始会话与请求保留。

主指标：缺陷交付错误放行数/比例；合格交付误拦数/比例；C 相对于 A、B 的配对变化；结构化决定完成率；额外模型请求、输入/输出 token 和时间。缺失或错误的模型阶段不能计为正确拦截，主比较只用三臂均完成且 native completed 的配对单元，所有失败仍报告。输入 token 包含 uncached/cache-read/cache-write 三个互斥分量；只累计已返回 assistant message 的用量，不估算失败流中缺失的用量。另给 A 已通过子集，区分 C 新增误拦与继承 A 的拒绝。模型 recipe 从当前 oMLX 的 models[model] 获取，并记录全局内存、调度和采样设置；快照缺失立即失败，凭据不写入快照。协议、代码、构建或模型 recipe 发生漂移则该轮失效。若记录器缺陷使整轮作废，可以修复后重新冻结并运行全轮，但必须保留原轮与原因；不得选择性重试正式失败样本。分别按场景和缺陷类型报告，不只给总体平均。

评分不由另一个 LLM 担任。代码 oracle 的边界输入不进入工具包，材料业务标准则明确公开；数学 oracle 校验特定证明步骤的白名单、证书系数/剩余类/整数域，实际展开多项式并穷举剩余类；它是该特定初等定理的有限证明证书检验，不是通用形式化证明器。调研 oracle 检查指定结构化事实及出处，不衡量开放网络检索与自由文本的全面质量。

## 结论规则与限制

如果 C 比 A 改善、但不优于 B，只能支持“增加一次检查有收益”，不能支持 Auditor 身份不可替代。如果 C 与 B 同样有效，优先讨论独立职责和授权边界的价值与成本，不能写成独立角色提升了准确率。如果各臂均无错误放行，报告未观察到增量质量收益；若误拦更高，则明确报告代价。若模型阶段大量未完成，则结论是不确定，而不是门禁有效。

样本是人为构造的局部压力测试，重复共享同一模型和材料，不能当成 24 个独立生产任务、不能据此估算真实流量中的失误概率或统计上普遍的必要性。没有开放网络深度调研、模型从零代码开发、复杂定理证明、Worker 返工、Allocator 与完整团队调度；本轮可论证“验收审核层在这些风险下是否有可测增量”，不能论证所有任务都必须保留 Auditor。

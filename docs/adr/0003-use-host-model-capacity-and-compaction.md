# Agent 执行由 DSH 负责

Flow 以 DSH Agent 为最小操作单元，负责配置任务输入、结果交付、工具能力及团队协作。Agent 的模型解析、模型元信息检查、请求组装、输出参数和上下文压缩由 DSH 负责；Flow 不增加模型容量预检或请求发送守卫，也不设置角色窗口、输出截顶和固定窗口兜底。

Flow 不挂载模型请求级中间件，模型请求次数限制一并删除。用量消费 DSH Agent 和 Session 已记录的事件，不通过拦截模型请求获得统计。

上下文压缩完全采用 DSH 官方默认行为。Flow 移除自身的压缩触发、固定余量、摘要请求改写和摘要输出覆盖，保留宿主服务接入与执行观测；官方默认的提前压缩可以继续发生。Flow 展示模型与上下文信息时仅消费宿主已提供的数据，不另建能力查询与校验链路。

“采用模型最大上下文”表示容量来源是实际模型窗口，不表示所有空间都可同时用于输入，也不要求压缩推迟到窗口耗尽。模型适配器的输出默认值不应被误写成模型硬性最大输出能力。

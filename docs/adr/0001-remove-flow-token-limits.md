# 取消 Flow 的 Token 与模型请求额度

Flow 当前在集群、管理节点、智能体、任务和压缩池之间分配 Token 与模型请求额度，并通过输出与身份上下文配置追加限制。决定取消这条链路中的 Token 和模型请求次数控制，以及 Flow 自设的上下文与输出上限，让模型执行完全归属 DSH Agent。

并发、智能体数量、工具调用次数、运行时限和团队轮次等限制继续有效。模型及部署实际支持的容量由 DSH 处理，Flow 不检查模型容量或模型请求参数。

Token 统计改为消费宿主已记录的用量，取消模型请求的额度、预留、付款、补额和结算链路。宿主未提供的用量标为未知或不完整，不承诺覆盖所有物理及辅助模型调用，也不作为执行准入条件。

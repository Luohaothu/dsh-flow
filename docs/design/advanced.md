# 进阶协作

## 独立工作区

需要真实隔离时使用宿主正常工作区与 sandbox 配置。共享工作区中的文件分工是协作约定，检查产物时按业务要求验证；Flow 不把目录说明当文件锁。

## 长任务与后台作业

模型循环、压缩和 jobs 由标准 Agent 处理。当前回合 idle 不能证明后台 job 已结束；需要结果时使用原生 job_output 等实际查询。Flow 的 Agent 容量只影响调度。

## 冷恢复

重新打开协作数据库并恢复原生 Session。恢复不主动补做业务工具，也不会根据已有文件推断成功。真正的任务接受保存在 Review 中；不能读取的执行证据保持未知。

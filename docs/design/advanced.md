# 高级使用

团队以主会话为单位保存。一个主会话可以启动多次运行；“运行记录”只切换查看对象，后续自然语言指令仍通过主会话下达。

## 描述完整需求

在 `/agent-team` 后说明目标、工作目录、预期产物、验收条件和需要保留的原文件。例如：

```text
/agent-team 核对当前工作区的报名数据，生成异常清单和汇总报告。
保留原始数据；报告需列出统计口径，并用原始行号标记异常。
```

不要把“文件已生成”当作目标完成。团队还需要按任务标准验收，并由独立审核记录结论。最后打开实际产物，核对原始要求。

## 执行配置

工作目录、能力、预算、模型、权限与上下文策略由宿主部署配置决定，参见[配置参数](/configuration/cluster)。`/agent-team` 使用当前主会话的工作目录；默认只授予部署允许的能力。显示设置不会调整模型、预算、并发或任务状态。

## 查看与阅读

拓扑实线表示实际派生关系，虚线箭头表示已记录通信。列表与拓扑使用相同的代理 ID、搜索和状态条件。筛选会保留命中节点的祖先；关系数据尚不完整时明确显示“正在补全关系”。

代理详情区分自身累计 Token、独立或共享额度、上下文占用与压缩记录。不同单位和共享额度不会相加。未知值、零和估算值分别显示。

阅读子会话向上滚动后停止自动跟随；有新消息时会提示“回到底部”。加载更早消息保留阅读位置。完整子会话只读；返回团队恢复选择、筛选与阅读状态。

## 下达后续指令

在原主会话输入补充、答复、暂停、继续或取消要求。选择节点、打开通信或切换历史不会自动发送命令。主会话中的执行工具核对团队归属并操作宿主；界面只在收到确认后显示结果。

关闭页面不会暂停或取消团队。重启宿主后，执行服务根据持久会话和账本恢复；重新打开原主会话查看状态。保留团队数据目录与宿主会话目录，才能回看历史。

## 故障定位

| 现象 | 查看位置 | 处理方式 |
| --- | --- | --- |
| 连接中断 | 智能体视图的最后更新时间 | 重试连接；旧数据保留并标为非实时 |
| 会话不可查看 | 对话区域的加载反馈 | 重试此区域；其他结构和信息仍可读取 |
| 等待用户 | 主会话的问题及代理详情中的等待原因 | 在主会话答复 |
| 状态未知 | 代理详情中的原始状态 | 根据宿主记录核实，不假定仍在运行 |
| 预算不足 | 代理详情中的额度和主会话执行反馈 | 核对部署预算；继续执行不会自动增加额度 |
| 设置无法保存 | 显示设置中的失败提示 | 草稿保留，可重试或取消 |

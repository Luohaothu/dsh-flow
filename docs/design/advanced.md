# 高级使用

团队以主会话为单位保存。一个主会话可以启动多次运行，界面默认展示未结束的团队或最近一次运行。需要核对特定运行时，在主会话说明目标运行，由主 Agent 按运行 ID 读取证据。

## 描述完整需求

在 `/agent-team` 后说明目标、工作目录、预期产物、验收条件和需要保留的原文件。例如：

```text
/agent-team 核对当前工作区的报名数据，生成异常清单和汇总报告。
保留原始数据；报告需列出统计口径，并用原始行号标记异常。
```

不要把“文件已生成”当作目标完成。团队还需要按任务标准验收，并由独立审核记录结论。最后打开实际产物，核对原始要求。

## 执行配置

工作目录、工具能力、工具预算、模型与权限由部署配置和创建请求共同确定，参见[配置参数](/configuration/cluster)。上下文、输出与默认压缩遵循宿主模型配置和官方行为。插件设置中的团队默认值用于之后新建的团队，主 Agent 读取这些默认值并按任务创建。模型可跟随主会话或固定选择；显示偏好只影响阅读方式。

## 查看与阅读

拓扑连线表示实际派生关系，列表与拓扑使用相同的代理 ID。可展开或折叠子树，通过图中节点或列表打开检查器；关系数据尚不完整时显示“正在补全关系”。通信消息在成员的原生会话内逐条呈现。

代理详情区分当前配置与最近实际模型、自身宿主已记录 Token 与完整性、独立或共享工具额度、宿主上下文与压缩记录。不同单位和共享额度不会相加。未知值、零和不完整统计分别显示。

阅读子会话向上滚动后停止自动跟随；有新消息时会提示“回到底部”。加载更早消息保留阅读位置。停靠检查器只读；点击成员名称进入完整原生会话，可切换对话与轨迹。团队未结束且成员未回收时，可以在该成员输入框发送文本；回收或团队终止后仍保留历史，并禁用输入。返回团队保留选择和折叠状态。

## 下达后续指令

团队整体目标、问题答复、暂停、继续或取消要求在原主会话输入。给某一成员补充文本时，可使用其完整原生会话。选择节点、展开通信卡或读取其他运行不会自动发送命令。主会话工具和成员会话驱动分别核对归属与执行资格，实际执行状态由宿主确认。

关闭页面不会暂停或取消团队。重启宿主后，执行服务根据持久会话和账本恢复；重新打开原主会话查看状态。保留团队数据目录与宿主会话目录，才能回看历史。

## 故障定位

| 现象 | 查看位置 | 处理方式 |
| --- | --- | --- |
| 连接中断 | 智能体视图的最后更新时间 | 重试连接；旧数据保留并标为非实时 |
| 会话不可查看 | 对话区域的加载反馈 | 重试此区域；其他结构和信息仍可读取 |
| 等待用户 | 主会话的问题及代理详情中的等待原因 | 在主会话答复 |
| 状态未知 | 代理详情中的原始状态 | 根据宿主记录核实，不假定仍在运行 |
| 预算不足 | 代理详情中的额度和主会话执行反馈 | 核对部署预算；继续执行不会自动增加额度 |
| 设置无法保存 | 显示设置中的失败提示 | 草稿保留，可重试或取消 |

# 任务委派

`flow_task` 的 delegate 动作一次创建并委派任务。输入包括完整工作说明和可选目标成员；交付要求直接写在 `objective` 内，输出包含任务与原生成员身份。省略目标成员时创建标准原生 Agent，父任务由调用者在本团队中的归属确定。

委派工具立即返回，父成员可以继续自己的工作。达到配置的 Agent 容量时任务透明排队，不在父工具调用里同步占用容量等待子成员完成。

同一 Agent 的原生活动互斥，符合派发条件的任务按持久化行序选择。上一成果尚未接受，不阻止空闲 Agent 执行下一项独立任务；暂停某个任务也不会阻塞该成员的其他独立工作。Flow 不保存预声明依赖图，需要前置结果的工作在结果到达后再委派。

修改任务使用 `task_id`、当前版本和实际变化。修改正在执行的任务须先暂停该任务；修改排队任务不需要暂停同一成员正在执行的另一任务。

成员自然完成的最终返回在原生 idle、flush 和再次空闲检查后发布 Result。委派者检查当前结果后接受或退回，退回沿用同一任务并增加版本。显式 `partial` 或 `blocked` 保留受阻事实，不能因成员空闲就当作完成。

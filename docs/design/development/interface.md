# 主会话与团队界面

主会话持有根任务、按需创建团队和成员、发送消息或取消活动。界面单独显示主会话入口与实际委派成员，并展示任务、交付与接受记录；原生对话由宿主组件渲染。

活成员会话保留原生输入、附件和取消操作。已结束成员的历史可继续只读查看；观察历史不会重启模型。任务接受、会话空闲和资源关闭分别呈现。

请求切换团队或成员时以当前观察请求为准，旧响应不能覆盖新的选择。模型与使用量来自已发生的原生事件，未取得证据时显示未知。

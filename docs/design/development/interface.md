# 主会话与团队界面

智能体视图保留派生树、拓扑画布与节点详情。调度精简只改变协作协议，不移除这些观察和导航能力。

主节点对应已有主会话，不创建额外根成员。其状态表示团队进度；成员节点显示原生执行状态。派生连线使用成员记录中的父会话标识，任务接受、会话空闲和资源关闭分别呈现。缺失或循环关系保留可访问节点并标记关系待补全，不补造连线。

顶栏团队按钮支持悬停或点击展开派生树，分开提供折叠、完整会话和右侧栏入口。树支持方向键、Home/End、Enter 和 Escape，关闭后恢复触发按钮焦点。已结束成员可隐藏；仍有活跃后代的已结束父节点继续显示。

桌面默认拓扑图，支持拖动空白处平移、滚轮和按钮缩放、适应视口、定位主会话与折叠子树。节点详情使用宿主 Dockkit 的对话/信息面板，支持分隔条与观察容器尺寸调整。信息区展示该成员的任务、当前和历史结果、与各自结果绑定的接受记录及消息；主节点还提供团队目标、真实成员汇总用量和运行事件。

窄屏默认层级列表，选择节点后显示完整详情，可返回团队或手动切换拓扑图。选择、折叠与画布状态按团队保存在当前客户端内存中，不形成新的后端约束。

嵌入对话和右侧栏使用宿主 SessionReference 与官方 Conversation，只读观察不会唤醒 Agent。打开完整会话保留原生对话、轨迹、输入、附件和取消操作；已结束成员只读查看历史。切换节点、关闭详情或卸载时释放观察引用。切换团队以当前观察请求为准，旧响应不能覆盖新选择；读取失败保留上次成功数据并提示重试。

界面只消费当前标准 Agent、任务、交付和接受记录，不恢复退役角色、预算、权限裁剪、写范围门禁或旧 schema 兼容分支。缺失模型与用量证据显示未提供，不把配置值当作实际调用。

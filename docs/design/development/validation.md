# 验证方法

验证围绕当前公开入口、控制平面和实际宿主行为开展。单元测试验证局部规则，确定性验收验证完整执行链路，浏览器检查验证原生导航和输入，真实模型场景验证任务是否按业务标准完成。这几类证据不能互相代替。

## 基础检查

```sh
pnpm install --frozen-lockfile
pnpm run typecheck
pnpm run build
pnpm test
pnpm run test:mock
pnpm run docs:build
```

`typecheck` 包含宿主端、Typert 生成与浏览器端声明。`test:mock` 使用原生接口和确定性模型，能够复现调度、通信、恢复及预算路径。真实模型验收使用 `pnpm run accept`；命令参数、模型设置和输出目录以 `tests/acceptance/run.ts` 与场景定义为准。

构建与验收使用独立工作区、数据库和宿主 profile。产物写入 `.artifacts/<run-id>/`，缓存、日志和生成报告不作为源代码提交。构建摘要用于检查验收期间是否发生代码漂移。

`tests/acceptance/build-fingerprint.ts` 集中定义源码树、构建产物、场景和配置补丁的覆盖范围，并供采集、完整性检查及前后比较共同使用。指纹缺失、尚未比较和已测得漂移分别报告；安装的依赖目录不参与源码树摘要。

## 检查范围

| 范围 | 需要核对的行为 |
|---|---|
| 启动意图 | 空需求保留输入；普通 user prompt 加载 skill；重复确认复用同一意图；参数冲突拒绝创建 |
| 主 Agent | 先评估、再创建并读取确认；主会话与后台总协调独立；进度与终态报告依据实际证据 |
| 团队工具 | 验证主会话归属；读取支持取消与有界等待；仅终态可 finalize，退出中的轮次必须等待 |
| 原生成员会话 | 快速切换与延迟读取不串会话；对话、轨迹、工具、图片和历史分页使用原生内容 |
| 输入生命周期 | 未回收且团队活跃时可文本续聊；回收或团队终止后输入禁用且历史保留；观察不创建执行 |
| 通信 | 初始任务为 user prompt；后续协作消息为 next-step 通知；八类消息可展开，审批样式来自结构化结果 |
| 团队观察 | 实际派生关系、运行隔离、版本去重、断线恢复、子树折叠、画布导航与未知用量 |
| 设置 | 执行默认值与显示偏好分别保存；失败保留草稿；所有导航等待守卫确认 |
| 任务验收 | 结果发布先完成结算；原子验收绑定当前计划、结果与 validation_ref；Worker 不能自行接受结果 |
| 调度与恢复 | 权限、分配、租约和保留的资源约束均满足要求才启动；未知副作用不盲目重放 |

## 浏览器验证

`tests/acceptance/checks/panel.ts` 通过实际插件包、标准组合、认证 API、原生输入框和提供方组件执行检查。截图、布局尺寸、接口响应与客户端异常保存在对应运行的 `artifacts/team-ui/` 中。浏览器需要 Playwright Chromium，可通过 `FLOW_CHROMIUM_PATH` 指定可执行文件。

每个界面改动应检查常用宽度、紧凑布局、浅深色主题、键盘导航和减少动态效果。成员导航还应覆盖执行中、未回收空闲、回收后和团队终态；检查器只读与完整成员会话的文本输入分别断言。

持久化观察夹具只验证展示、读取和分页，不证明同等数量的模型并发执行。截图证明可见状态，不证明工具执行结果或资源释放；后者需要核对原生会话、控制平面状态和实际产物。

## 原生执行能力

`tests/acceptance/native/mock-runtime.test.ts` 使用真实 DSH 工具验证文件、终端、后台作业、网络拒绝及管理者在同回合查询本人回执。浏览器场景另外验证 Orchestrator 本人的导航、snapshot 和点击。能力声明、实际调用、返回结果和当前计划/结果绑定均需核对。

`pnpm test:manager-native` 串行运行额外的冷恢复、真实后台作业取消和公开网页成功路径。冷恢复使用同一数据目录重启真实 DSH 宿主，核对管理者授权、工具挂载、实际文件/终端调用及当前发布的验收绑定。该命令独立于确定性 `test:mock`；其中网页测试需要可用的公开网络。在需要代理的环境，显式向隔离宿主提供无凭据的 HTTP(S) 代理地址：

```sh
FLOW_NATIVE_FETCH_PROXY=http://127.0.0.1:7890 pnpm test:manager-native
```

未设置时使用直连；此参数不修改全局代理，也不关闭原生网络安全检查。测试会核验终止状态、真实正文、本人原生回执和验收引用，报告保存在 `.artifacts/integration-manager-native-*/`。冷恢复可独立运行，不需要公开网络：

```sh
node --import tsx --test tests/integration/native-management-recovery.test.ts
```

## 真实模型与规模

真实模型场景固定任务、模型、工具预算、并发与验收标准，分别报告业务结果、实际验收依据、宿主已记录用量和运行限制。规模实验分别记录身份总数、驻留峰值、Agent 调度许可、独立观测的提供方请求并发、任务完成数、层级深度和质量指标，不能用已创建身份数代替成功执行数。

通过结论必须来自本次检查。无法运行的场景明确说明原因；静态阅读、类型检查、夹具展示和真实业务验证分别报告。实际结果不完整、环境受阻或验收仍有未解决问题时，不标记为全部通过。

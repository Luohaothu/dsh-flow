# 验证方法

当前测试验证标准 Agent 与轻量协作，而不是维持旧测试数量。旧正式计划、角色预算、租约、分配、写范围门禁和效果账本夹具已随实现删除。

## 自动检查

`pnpm typecheck` 检查 Host/Client 分离的类型图；`pnpm build` 构建可安装插件；`pnpm test` 验证协作不变量与独立 Provider 行为；`pnpm docs:build` 检查文档引用。

原生 integration 单独串行运行。Provider 设置测试在隔离 profile 中创建、编辑、冷重载和删除自有提供方，必须保留原配置且不发送模型请求。

## 界面交互

团队拓扑使用当前协作快照，验证真实父会话连线、主节点不增加成员、折叠不触发会话导航、缩放/平移/适应视口、顶栏树的键盘与焦点、当前和历史结果的接受记录绑定、已结束过滤保留活跃后代的祖先、断线恢复，以及 390px 窄屏列表/详情/手动拓扑。截图由生产组件在隔离原生 web Host 中生成，示例数据不代表真实业务产出。

## 原生能力

标准 Agent 与 Flow 成员使用相同 profile、preset、模型和权限，核对实际请求工具与 read/write/bash/jobs/web/MCP 结果。模型可用脚本产生调用，但业务工具必须真实执行。原生冷恢复、取消排空、输入不重复和只读历史观察各自有明确证据。

当前原生对照已实际执行文件读写、前台 shell、后台任务及其 `job_output`、公网 `web_fetch` 和额外插件工具；同时覆盖同回合 32 次读取、15 轮后续输入和冷恢复。首次域名被本机 Fake-IP 解析触发原生 URL 拒绝的记录保留，随后使用有效 TLS 的公网 IP 地址完成同等验证，未放宽原生策略。

Playwright MCP 单独核对普通 Agent 与 Flow 成员的相同工具目录和原生 `ask` 策略，并分别真实导航、读取各自测试页面的快照。只替代模型生成，不替代浏览器和 MCP 调用；首轮本机 socket 路径过长的失败也保留。不能把这些隔离测试截图当作真实业务完成证据。

## 确定性协作机制

验证对象是协议和状态不变量，不以模型生成的报告、分工、来源数量或耗时排名判断设计优劣。使用真实 Controller/SQLite、有界状态切面、受控故障和固定脚本模型的真实原生工具链，排除内容生成随机性。

有界机制测试包含 106 条独立状态轨迹及 128 次拒绝后的持久化零变化检查，覆盖合法调用者、当前版本/结果、两兄弟及递归子任务、根完成原子性。它们是明确范围内的状态检查，不是无限异步交错的形式证明；最终构建与全套测试结果见[当前实施验证](https://github.com/Luohaothu/dsh-flow/blob/main/docs/plans/native-agent-simplification-validation.md)。

命令测试覆盖并发、顺序及冷重试，并在三处注入故障：意图记录后、团队提交后、原生输入已 spliced 后。真实 SQLite 重开验证同一提交只有一个意图、团队和输入；改变正文或附件仍冲突。Session 的持久切点通过受控快照模拟，不能称为真实进程 kill、磁盘 fsync 或任意断电恢复验证。

单委派正常成功路径的真实原生调用为主会话 `[flow_task, read, flow_review, flow_result]`、成员 `[write]`，其中 Flow 调用只有三次。成员自然返回发布交付，委派者接受后主会话声明根完成，不需要模型创建、成员显式 result、根自审或 finalize。这个数量是协议调用数，不是模型请求次数或耗时下界，也不限制业务工具调用。

还需检查 idle→flush→再次空闲的发布顺序、partial/blocked 的保留、下一独立任务不等待旧成果接受，以及结束时只回收自有成员。测试不证明业务文件正确，也不证明所有外部工具效果恰好一次；活性仍依赖原生调度公平及 create/idle/flush/cancel 最终返回。

## 模型实验的历史范围

方向调整前的 A 股实验保留原登记、首次结果、失败与中断。基线四段及优化普通 Agent 首段自然结束，优化团队首段因用户调整范围而安全中止，后两段未运行。业务内容检查仅为历史观察，不用于决定优化优劣；没有完整优化配对，不支持性能排名或普遍提速结论。原执行方案与观察草稿见[归档索引](https://github.com/Luohaothu/dsh-flow/blob/main/docs/plans/archive/2026-10-13/README.md)。

长任务不得因旧工具次数或角色轮数被终止；测试 runner 的超时只保护测试过程，不成为产品执行限制。保留的实验脚本和记录不表示当前仍需继续模型对照。

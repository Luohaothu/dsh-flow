# 消息路由

协作智能体提供自身发送方法，并向消息队列注册异步接收回调。消息包含发起者、接收者、正文、可选任务和 request/notice 意图。发送方保存消息并提交队列后返回。

消息队列按接收会话寻址，只负责异步通信交接。接收回调记录接管，并负责自身原生输入和执行状态。需要启动的执行工作由系统封装为作业，交给固定并行容量的智能体执行队列。

消息入队、接收回调接管、原生交付分别记录。接管通过 `message-received` 事件表达；原生会话记录带消息身份的 `user/message` 事件后，消息状态才成为 `delivered`。原生 Inbox 继续负责模型输入与步骤进入。

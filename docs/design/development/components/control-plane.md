# 协作控制

协作规则模块保存团队归属、任务委派、当前结果、接受记录和成员消息，校验真实会话身份与控制权限。控制器保留外部接口并转交操作。

候选任务按持久化行序选择，委派保存后立即返回。系统将执行工作封装为作业，智能体执行队列按固定并行容量调度，同一会话的作业串行执行。排队与占位状态由系统内部维护；成果等待接受时，已结束的作业释放执行单元。

父任务从本团队归属推导：所有者使用本团队根任务，成员使用当前任务。同一个原生智能体可在不同团队分别拥有根任务和执行成员任务，按会话共用一个协作智能体对象。

协作规则维护操作幂等、真实调用者、任务版本、当前结果、委派者决定和子任务义务。智能体确认自身原生活动已空闲并持久保存日志后，协作规则发布可检查结果；结果就绪与委派者接受分别记录。

根结果、根任务接受和团队完成在同一事务提交。团队完成后，系统安排协作智能体关闭自身原生资源；只回收 Flow 创建的成员，主会话继续可用。

暂停、继续与取消先由协作规则校验并保存，再交给对应智能体的控制回调。智能体维护自身原生执行状态，用户明确期限由系统触发同一控制接口。

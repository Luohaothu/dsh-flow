# 看板与宿主界面

看板以 Agent 树展示团队的组织和执行情况。团队、作业和 Agent 各自有状态：团队可以持续活跃，某份作业已经完成，而成员暂时空闲。界面分别呈现这些信息，便于继续派发任务或检查已有结果。

## 选择团队与成员

运行栏列出当前进程中的团队，显示发起会话、根摘要、运行状态和未结束作业数。节点卡片显示成员身份、模型、任务、状态与用量，连线表示实际父子关系，群框表示群成员范围。

<AgentTreeFigure src="/images/agent-tree-design/overview.svg" alt="团队运行栏、Agent 树、群框与节点详情区" caption="团队看板：由运行定位团队，由节点进入详情" />

点击节点查看概况、收件箱与用量。选择消息发送者或群成员时，界面展开目标所在分支并定位节点。折叠只改变显示范围，成员仍按各自状态工作；展开时恢复最新信息。

平移、缩放和增量更新保留用户视点。切换团队后，恢复该团队保存的选择、折叠和视口状态。键盘通过方向键移动和展开分支，Enter 选择节点，Escape 关闭覆盖详情。

## 阅读状态与结果

运行中的成员显示 `running / waiting / idle` 等逻辑状态，终止成员显示 Flow 判定的最终结果。资源清理以单独标签呈现，包括清理中、失败原因或放弃清理的持续标记。

作业详情展示发送方、接收方、上级作业、提交记录、结果和仍在继续的子作业理由。查看任务进展时，沿作业关系追踪拆分；查看组织时，沿 Agent 父子关系定位成员。

收件箱展示该节点实际收到的消息。优先级和阅读状态分别呈现，点击消息可查看摘要并重放投递路径。黑板写入时，写入方卡片出现气泡，群详情更新共享记录。

## DSH 中的入口

全局“智能体”面板展示各会话发起的团队，并提供返回发起会话的入口。会话内“智能体”页签只展示当前会话对应的团队，团队下拉用于选择具体运行。

<DshHostMotion scene="session" />

成员观察侧栏展示宿主原生会话，包括用户与助手内容、思考和工具记录。选择成员打开或切换观察对象，关闭侧栏返回团队上下文。观察操作读取会话，成员执行仍由任务与消息机制驱动。

每个宿主适配器提供独立 Web 面板；具备界面扩展能力的宿主同时提供原生面板。两者共用看板数据和交互规则。

## 停止操作

停止入口明确展示目标与范围。停止某个成员会影响该成员及其当前逻辑后代；覆盖整棵树时，操作显示为“解散团队”，同时取消该运行的未结束作业。

提交操作后先显示等待结果，随后通过事件或快照更新完成或失败反馈。HTTP `202` 表示请求已接管，资源处理完成由后续结果确认。已经提交的作业结果继续保留。

只取消一项任务时，使用作业取消操作，成员可以继续处理其他工作。任务取消、成员停止与团队解散分别对应不同范围。

## 快照、事件与重连

客户端先取得运行列表快照，再从列表游标订阅事件；选定团队后取得该团队快照，再从对应游标接收增量。运行列表和各团队分别维护顺序号，客户端按对象 ID 更新展示并跳过重复事件。

连接中断时优先从上次游标续订。游标无法续接时，重新确认团队是否有效并读取新快照。进程重启后先重新取得认证信息和运行列表，旧运行句柄显示为失效。接口见 [看板查询与事件订阅](design.md#查询与事件订阅)。

# 运行时与宿主适配

Flow 的编排层使用 Agent、Mailbox、Group 和作业对象表达协作。运行时管理这些对象的存续，宿主适配器将模型输入、工具调用、会话恢复和资源释放落实到具体宿主。

## Context 与对象归属

Context 是同一编排环境中的对象管理者，负责登记、查找和释放 Agent、Mailbox、Group 与适配器。进程内接口以对象引用协作，ID 用于工具调用、持久化和外部寻址。

Agent 的逻辑父级用于管理和控制传播。会话、工具、监听及原生执行资源归属每个实例自身。更换父级时，这些资源继续由原实例使用。

Context 整体关闭时，停止新的创建和注册，解散群，释放 Agent 及其 Mailbox，最后释放宿主适配器。完成表示运行时绑定及约定的后端资源处理已经结束。

## Mailbox 与通知

Mailbox 保存消息、过滤规则、来源评级与已读状态。它提供按 ID、未读状态和查询条件读取消息的接口；查询摘要与读取正文分别采用相应的读取语义。

Agent 维护通知进度，按消息优先级和轮次边界整理通知。适配器只接收经过 Flow 整理的输入模式、通知用途和优先级，并按宿主能力落实执行时机。完整规则见 [消息与协作](communication.md)。

## HostAdaptor 与 HostAgent

`HostAdaptor` 是宿主适配契约，`HostAgent` 是与一个原生实例对应的宿主无关对象。Flow Agent 持有 HostAgent，并通过适配器完成以下操作。

| 能力 | 完成含义 |
| --- | --- |
| 创建和恢复实例 | 原生实例、配置和工具已准备好，供 Flow 完成登记与发布。 |
| 发送输入 | 宿主已接管输入，后续模型执行按输入模式推进。 |
| 导出、导入历史 | 按适配器规定的序列化格式传递会话内容。 |
| 总结和合并上下文 | 返回符合约定格式的完整文字结果。 |
| 订阅事件 | 提供轮次结束、用量及相关运行事件。 |
| 释放实例 | Flow 执行关联及所选后端资源处理已完成。 |

适配器初始化工具时绑定本次创建的 Flow Agent 和 Mailbox。工具侧的对象 ID 由适配器解析，真实调用者由宿主注入，模型提供业务参数。

## DSH 映射

DSH 适配器在稳定宿主 Context 下创建原生实例，在各实例自己的作用域中安装模型、权限和工具。Flow 的父子树由 Flow 维护，DSH 会话来源信息用于记录历史来源。

| Flow 约定 | DSH 适配 |
| --- | --- |
| `followup / steer / notice` | 分别使用原生 `followup / steer / inject`。 |
| 主动等待返回 `registered` | 工具返回登记结果，并用 `concludeTurn()` 结束当前轮次。 |
| 主动等待返回 `matched` | 返回匹配消息元信息，继续当前轮次。 |
| `turn-end` | 使用已记录的原生 `turn/end`。 |
| 顶层作业完成 | 向发起会话提交 `followup`，携带团队与作业查询信息。 |
| 材料读取 | 将可读取内容呈现为宿主支持的内容块。 |

等待期间，适配器在输入即将进入模型时查询 `hasPendingWait()`。普通输入暂缓，优先通知和等待完成提示可以进入。等待完成后，先接管完成提示，再恢复暂缓输入。

## 会话恢复与资源收尾

冷恢复按持久化的 Profile 重新安装完整模型配置、初始权限和工作区边界。恢复前清理旧实例尚未消费的 Flow 通知，保留用户指令与任务输入；下一次模型请求收到新的恢复说明。

DSH 释放区分发出取消请求、等待执行结束及最终资源销毁。适配器合并重复关闭请求，在优雅收尾与立即清理之间按约定升级，并保留可供恢复的非 Flow 待处理输入。

宿主对权限、辅助模型调用和资源清理的具体处理见 [DSH 后端适配](design.md#dsh-后端适配)。接口签名见 [HostAdaptor](design.md#宿主适配器)。

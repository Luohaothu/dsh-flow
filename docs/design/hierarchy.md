# 任务关系

任务通过 `parent_id` 记录实际委派关系。父任务由调用 Agent 在当前团队中的身份确定：团队所有者委派时归本团队根任务，成员委派时归其当前任务。工具不接受任意指定父任务，也不预建依赖等待图。

同一个标准原生 Agent 可以是一个团队的成员，同时是另一个团队的所有者。归属按本次操作的团队判断；角色通过职责和原生配置表达，不由层级或固定权限等级决定。成员可以递归委派，或将下一项独立工作交给本团队已有成员。

只有需要独立交付的工作才建立子任务。业务需要前置交付时，委派者收到并检查该交付后再发出后续任务。层级记录责任关系，不为简单任务增加人数或步骤。

委派者接受或退回执行者的当前结果。修改任务后，旧版本结果不能完成新的要求；子任务未经合法接受或取消，祖先任务不能完成。接受由实际委派者负责；任务需要时可以委派核验或评审工作，但该角色的建议不替代委派者决定，也不增加固定 Auditor 验收门槛。

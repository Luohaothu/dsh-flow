# 快速上手

在主会话输入 `/agent-team` 和需求，团队负责分解、执行与独立复核。后续指令继续在原主会话输入；“智能体”视图提供只读观察。

需要按完整案例操作时，阅读 [DeepSeek 实战步骤](/step-by-step)：从模型配置和工作区选择开始，逐步核对工具计算、独立复核与交付文件。

## 安装与启动

当前基线为 DSH `0.1.7-rc.2`、pnpm `12.9.1`。本实现使用仓库提交的宿主提供方接口补丁，普通同版本 npm 宿主尚未包含这些扩展。请从仓库构建运行，参见[开发环境搭建](/development/setup)。

```bash
pnpm install --frozen-lockfile
pnpm run build
```

随后按[独立调试实例的安装和启动步骤](/development/setup#_3-安装到独立调试实例)安装标准插件组合并启动 `web` 配置方案。覆盖配置要求插件已安装，不能直接作为安装命令使用。

先配置可调用工具的模型服务，并在主会话选择工作区。插件设置包含团队执行默认值与显示偏好；模型、能力、权限和预算共同约束实际执行。

## 发起任务

在主会话的原生输入框提交：

```text
/agent-team 帮我核对活动预算：场地费 1500 元、物料费 680 元、茶歇费 420 元，
总预算 3000 元。请安排计算与独立复核，告诉我总支出、剩余预算及是否超预算。
```

提交后先出现用户需求，主 Agent 加载 skill、评估复杂度和验收标准，再调用创建工具并读取实际启动状态。成功后顶栏出现“智能体团队”按钮，会话视图增加“智能体”。空需求会保留输入并提示补充。同一意图以相同参数重试会复用已有团队；终态结果核对后主 Agent 收尾，历史仍可查看。

## 查看分工

悬停或点击顶栏“智能体团队”，查看总协调及派生树。展开箭头只展开子代理；点击名称进入对应的完整原生会话，可切换对话、轨迹等标签。未回收且团队未结束的智能体保留输入框，可发送文本补充消息；回收后仍可查看完整历史。按方向键浏览，按 Enter 打开，按 Esc 收起并返回触发按钮。

进入“智能体”视图，可以在拓扑与层级列表之间切换。拓扑支持平移、缩放、适应视口和定位总协调。点击节点打开只读检查器，查看该代理的原生对话、状态、父子关系、预算、累计用量和上下文；从检查器可进一步打开完整原生会话。

拓扑连线表示实际派生关系。通信在对应成员的原生会话中呈现为可展开的记录。不同主会话相互隔离；团队工具可按运行 ID 读取同一主会话的各次执行，界面默认展示未结束的团队或最近一次运行。

## 回到主会话

团队的补充要求、问题答复、暂停、继续或取消，在主会话直接输入。给具体智能体补充文本，可进入其完整原生会话；通过顶部面包屑返回所属主会话。选中代理、展开树、切换视图或关闭详情只改变观察状态，实际消息需在输入框提交。执行状态由宿主确认后更新。

团队结束后，主会话显示结果，节点仍可回看。资源“已回收”与执行结果分别显示；缺少数据的用量显示“尚未上报”，不能当作零。

## 插件设置

从插件管理中的标准 `dsh-flow` 卡片进入设置。团队默认值可调整模型、预算、规模、并发与执行限制；这些设置用于之后新建的团队。显示与阅读偏好包括默认视图、已结束节点、动态效果、Token 格式和对话自动跟随。编辑草稿后点击保存才生效；保存失败会保留更改。离开时可保存并离开、放弃更改或继续编辑。

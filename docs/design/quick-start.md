# 快速上手

本页以活动预算核对为例，带你完成一次团队任务：提交需求、查看分工、补充要求，再确认结果和交付文件。

## 开始之前

以下步骤默认你已启动 DSH、安装并启用 `dsh-flow`，且宿主中已有可用模型。插件直接使用宿主中已配置好的模型；团队默认“跟随主会话”，使用主会话当前选中的模型。

尚未安装插件时，先按[开发环境搭建](/development/setup)完成构建、安装和启动。当前实现需要仓库提供的宿主接口补丁，安装要求见 [dsh 兼容性](/development/compatibility)。

## 1. 选择工作区和主会话

打开 DSH，在准备存放任务文件的工作区中新建或打开一个主会话。核对输入框旁显示的工作区和模型；本例会在该工作区生成 `budget-report.md`，需要允许文件读写。

下面的截图用于定位工作区和模型选择入口。模型名称以你已配置并选中的模型为准。

[![主会话输入框旁的工作区和模型选择入口](/images/deepseek-case/01-workspace-model.png)](/images/deepseek-case/01-workspace-model.png)

## 2. 输入需求并发送

在主会话输入框中粘贴以下内容，然后点击“发送消息”：

```text
/agent-team 帮我核对活动预算：场地费 1500 元、物料费 680 元、茶歇费 420 元，
总预算 3000 元。请安排计算与独立复核，并在当前工作区生成 budget-report.md。
报告应包含费用明细、计算式、总支出、剩余预算及是否超预算。
完成后请告诉我复核结论和报告的文件位置。
```

`/agent-team` 后面的文字就是交给团队的需求。用于自己的任务时，写清楚输入材料、希望得到的产物和验收要求即可，团队会安排分工、执行和独立复核。

发送后，等待主 Agent 确认团队已创建。创建成功时，顶栏会出现“智能体团队”按钮，会话中增加“智能体”标签。如果主 Agent 询问缺失信息，直接在当前主会话回答；只输入 `/agent-team` 而没有需求时，按提示补充任务描述。

主会话保留你的需求和主 Agent 的回复。如下图，上方是提交的预算任务，下方是团队创建确认及当前工作说明；底部输入框用于继续交流。主会话与详情截图使用演示模型，实际模型、成员名称和回复内容以你的任务为准。点击图片可查看大图。

[![主会话中显示用户需求、团队已创建的回复、当前任务和继续交流的输入框](/images/quick-start/main-running.png)](/images/quick-start/main-running.png)

悬停或点击顶栏“智能体团队”，可以在聊天界面中展开成员树，查看各成员的角色和运行状态。点击成员名称可进入其完整会话，点击“查看智能体”进入团队视图。

[![主会话顶部展开智能体团队成员树，显示成员角色、运行状态及查看智能体入口](/images/quick-start/main-team.png)](/images/quick-start/main-team.png)

## 3. 查看团队分工和进度

点击“智能体”标签，查看团队的拓扑图或层级列表。图中的连线表示成员的派生关系；每个节点展示职责和当前状态，成员名称、数量和分工会随任务变化。

[![在智能体标签中查看团队拓扑、成员职责和当前状态](/images/deepseek-case/04-topology.png)](/images/deepseek-case/04-topology.png)

点击一个子代理节点，会打开该成员的详情弹窗。宽屏下左侧是“对话”，右侧是“信息”；窗口较窄时，通过“对话”和“信息”标签切换。

[![点击执行成员后打开详情弹窗，左侧显示成员对话，右侧显示基本信息和关系](/images/quick-start/agent-details.png)](/images/quick-start/agent-details.png)

| 弹窗区域 | 可以查看什么 |
| --- | --- |
| 对话 | 成员收到的任务、执行说明和工具调用；展开工具记录可查看输入与返回结果 |
| 基本信息 | 当前状态、职责、配置模型、最近实际使用的模型，以及运行或等待时间 |
| 关系 | 成员所在层级、父代理和子代理，可点击关联成员继续查看 |
| 用量与预算 | 当前成员已记录的 Token 用量、预算总额、已用与剩余额度 |
| 上下文与会话记录 | 上下文已用量与上限、最近压缩时间（如有），以及成员会话和所属主会话的标识 |

向下滚动右侧信息栏，可以查看用量、预算和上下文。标为“尚未提供”或“可能不完整”的数字，应按界面提示理解。

[![向下滚动成员信息栏，查看用量、预算、上下文和会话记录](/images/quick-start/agent-usage.png)](/images/quick-start/agent-usage.png)

详情弹窗内的对话只读。需要给该成员补充文本时，点击“打开完整会话”；通过顶部面包屑可返回所属主会话。关闭详情弹窗即可继续查看团队拓扑。

## 4. 补充要求或控制任务

切回主会话的“对话”标签，直接输入补充要求或回答团队提出的问题。例如：

```text
请在报告末尾再加一句预算结论，方便我直接转发。
```

需要暂停、继续或取消时，也在同一主会话发送指令：

| 你想做什么 | 可以输入 |
| --- | --- |
| 暂停执行 | 请暂停当前团队任务，等我补充信息。 |
| 继续执行 | 请继续当前团队任务。 |
| 取消执行 | 请取消当前团队任务。 |

发送后查看主 Agent 的答复和团队状态，确认指令已生效。选中节点、展开成员树或关闭详情只改变浏览位置。

如果只需要给某个成员补充信息，可以打开它的完整会话发送文本；成员已回收或团队已结束时，仍可阅读历史，但不能继续输入。

## 5. 确认结果和交付文件

团队完成后，回到主会话查看最终答复、复核结论和文件位置。下图展示主 Agent 如何在同一个聊天界面中返回预算结论与报告入口；顶栏同时显示团队已完成。

[![主会话返回总支出、剩余预算、独立复核结论和报告文件入口，顶栏显示团队已完成](/images/quick-start/main-result.png)](/images/quick-start/main-result.png)

在工作区打开生成的 `budget-report.md`，核对以下内容：

| 检查项 | 本例的预期结果 |
| --- | --- |
| 费用明细 | 场地费 1500 元、物料费 680 元、茶歇费 420 元 |
| 总支出 | `1500 + 680 + 420 = 2600` 元 |
| 剩余预算 | `3000 - 2600 = 400` 元 |
| 是否超预算 | 未超预算 |
| 交付文件 | 当前工作区中的 `budget-report.md`，包含明细、计算式和结论 |

若报告缺少内容、计算不符或文件未生成，在主会话指出具体问题并要求补齐。执行者提交报告后还需要独立复核，确认最终答复说明了复核结果；需要查看过程时，可以从“智能体”中打开负责复核的成员记录。

任务结束后仍可查看成员历史。“已回收”表示成员资源已释放，是否成功完成任务应结合最终答复和实际产物确认。

## 调整设置并开始自己的任务

从插件管理中的 `dsh-flow` 卡片进入设置。团队默认值可调整模型、预算、规模、并发与执行限制，保存后用于新建团队。模型默认“跟随主会话”；如需固定团队模型，从宿主已配置的模型中选择即可。

显示与阅读偏好包括默认视图、已结束节点、动态效果、Token 格式和对话自动跟随，编辑后点击保存生效。

熟悉流程后，将示例需求替换为自己的目标、输入材料和验收要求。复杂任务的组织方法见[高级使用](/advanced)，具体参数见[智能体配置参数](/configuration/agents)和[集群配置参数](/configuration/cluster)。

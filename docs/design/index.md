# Flow 智能体团队

Flow 为智能体提供树状团队、消息协作、结构化作业和可观察的运行环境。会话 Agent 负责与用户沟通，团队根负责组织成员，各级 Agent 根据任务自主拆分工作、交换信息并交付结果。

团队模式是一份创建图纸，帮助 Agent 复用已经总结的组织结构和管理经验。作业记录一次正式委派的任务及其交付要求。团队可以持续存在，接续处理多份作业。

## 从概念到协作

Agent 拥有独立会话，通过逻辑父子关系组成团队。普通消息支持讨论与澄清，群聊和黑板支持共享信息。需要明确交付和运行状态的任务采用作业，由派发者给出背景、需求、验收标准和结果 schema。

## 运行与观察

Flow 的编排对象通过宿主适配器调用原生 Agent。宿主负责模型与工具执行，Flow 维护组织关系、通信和作业记录。看板以 Agent 树呈现团队，并分别展示作业结果、Agent 状态和资源清理进度。

## 总体定位

dsh-flow 旨在扩展 dsh 中标准智能体团队的能力，提供预置的 agent 组织模板、agent 团队可视化面板以及共性 agent 团队运行时基础设施，方便用户在处理复杂任务时直接复用成熟的 agent 团队组织形式，降低 agent 团队组织架构决策难度，复用已有研究的经验成果。在此基础上，dsh-flow 提供了高度抽象的公开接口，用户可通过公开接口设计自己的团队编排，并与其他系统部分合作，以此扩展插件的现有模式。

## 架构设计

dsh-flow 包括三个方面：面向用户的界面看板，后端 agent 运行时，以及 agent 编排系统。其中，看板系统负责在 dsh 界面上渲染**智能体**选项卡，提供对当前运行智能体团队的直观展示能力；agent 编排系统负责定义插件的核心概念，包括智能体、消息、群组等，在此基础上提供开放接口，供用户扩展自己的智能体及团队架构模型，编排系统自身预置的智能体及团队架构也通过这套接口进行描述；最后是后端 agent 运行时，该层次将 agent 团队编排转译为 dsh 原生 agent 及 team 的业务请求，并提供运行时调度和消息队列支撑 dsh 特有的协作语义。

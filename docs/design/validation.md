# 验证方法

验证证据应说明检验的契约、实际执行的步骤和观察到的结果。文档构建验证内容能否生成站点，浏览器检查验证页面能否正确展示；运行时行为与真实模型任务需要各自的执行证据。

## 文档与示例

在仓库根目录安装依赖后构建文档：

```sh
pnpm install
pnpm docs:build
pnpm docs:preview
```

构建后检查导航、文内链接、锚点、下载模板和图示。桌面与窄屏分别检查表格、代码、树形图和交互演示；切换页面后确认 Mermaid 已渲染，设计图可放大，演示控件可操作。

模板校验覆盖 YAML 解析、参数默认值、角色引用、`use.id / use.with` 组合、完整展开路径与群成员选择。按不同参数展开同一模板，核对成员数量、真实父子关系和引用根的对应关系。

## 团队与作业契约

下表列出实现应提供证据的协作场景。每次验证记录对应提交或版本、执行命令、输入、结果与证据位置。

| 场景 | 需要确认的结果 |
| --- | --- |
| 创建根后派发作业 | 创建返回运行句柄；根就绪后独立接收顶层作业。 |
| 多层模板引用 | 引用节点就是对方的根，参数、指引、角色与群路径正确展开。 |
| 同一团队持续使用 | 顶层作业完成后，根和成员可承接后续作业。 |
| 同一成员多份作业 | 每份作业独立记录状态，Agent 可自行交替处理。 |
| 格式纠正 | 首次格式失败后有两次纠正机会，合格结果保存后完成。 |
| 提交前处置子作业 | 取消不再需要的任务，逐项保留仍需继续的理由。 |
| 递归取消 | 取消未结束后代并保留已提交结果，成员仍可处理其他作业。 |
| 顶层结果交付 | 会话 Agent 被主动通知，读取实际结果后向用户汇报。 |

## 通信与宿主行为

通信验证分别观察消息入箱、通知接管和正文读取。确认来源评级决定本地优先级，主动等待可匹配已有或后续未读消息，临时处理优先消息时原等待仍然有效。

宿主验证使用实际适配器，检查模型与权限安装、工具绑定、轮次结束、输入暂缓、会话恢复和关闭操作。用受控模型验证时序与状态，再通过真实模型场景确认工具选择、结构化提交和实际交付。

## 看板与结果证据

看板验证以实际快照和事件驱动页面，核对 Agent 树、作业关系、消息、黑板、用量与清理进度。停止操作分别检查请求接管、逻辑终止和资源处理完成。断线后检查视图是否能从游标或新快照恢复。

真实模型任务应保留任务说明、模型会话、作业记录和实际产物。按验收标准独立核对产物内容；模型在对话中声称完成，只是需要进一步验证的输出。尚未执行或没有证据的项目保持未验证状态。

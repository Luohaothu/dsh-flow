# 标准 Agent 机制验证

状态：实现、自动验证和本地发布均完成。验证对象是协议和状态，不比较模型报告或具体业务行为。

## 最小协议

有 n 个实际委派节点的正常成功树，需要 n 次委派、n 次成果发布、n 次委派者决定和一次根完成。自然最终返回自动发布成果时，模型显式 Flow 调用可以只需 **2n+1** 次：delegate、review、root result。read、额外确认、本人自验收和成员显式 result 都不是该正常路径必需步骤。

该数量是协议调用数，不是 provider 请求次数或墙钟下界；多个调用可能同属一次模型响应，业务检查仍使用原生工具。真实原生固定模型测试的单委派路径为 main [flow_task, read, flow_review, flow_result]、member [write]，其中 Flow 调用恰为三次。

相对上轮规范路径，固定的意图读取、模型创建团队和根自验收三项管理操作被删除。成员自然返回在旧底层也已有支持，因此没有把旧指南的显式成员 result 当作无法避免的下界或强行计入节省量。

## 状态不变量

| 不变量 | 可核验边界 |
| --- | --- |
| 同一提交只有一个意图、团队和原生输入 | 并发、顺序、冷重试；三个持久切点恢复 |
| 子任务未合法接受或取消时不能完成祖先 | 两兄弟及递归任务的有限状态切面 |
| 拒绝不产生半结果、半完成或事件 | 全部协作表及事件序号逐行前后相等 |
| 结果就绪晚于原生 idle 与 flush | 延迟 flush、再次运行和已有显式受阻结果 |
| 只接受当前版本、当前结果及合法作者交付 | actor、旧版本、同版本旧结果头反例 |
| 根完成没有本人自验收 | 根结果、根 ACCEPTED、团队 completed 同事务；零根 Review |
| 下一独立工作不等待上一成果验收 | 同 Agent 稳定行序、暂停和排队修订轨迹 |
| Flow 不关闭原生主会话 | 只取消、flush、释放自有成员；延迟 factory 仍回收 |

新增有界测试包含 106 条独立状态轨迹；128 次拒绝逐行检查持久化零变化，根完成有 111 次正确拒绝和 11 次成功。已绑定最终 Controller/Store 源码指纹重新运行；统计不能代替边界与断言说明。

三个命令故障切点为：意图持久化后但团队提交前、团队提交后但输入入队前、输入已 spliced 但 handler 返回前。Flow SQLite 为真实持久层，原生 Session 检查点为受控快照；这不等于真实进程 kill、磁盘 fsync 或任意崩溃模型的证明。

## 确定性的简化

命令创建和根完成删除了模型获取创建身份、模型创建及根自验收等固定往返。单一 objective 与身份收据减少重复传递；结构性依赖环随预声明图删除。修订排队任务不再取消无关工作，成果未验收也不占住空闲 Agent 的执行槽。

保留 ready 是为了发布后的持久检查点，并不保证 Agent 以后永不再运行。接受是跨 Agent 的责任决定，不是固定评审角色。逻辑完成与资源 drained 分别表达；不强迫控制工具同步等待自身取消。

组合反例也完成 RED→GREEN：已有成员兼任另一团队的 owner 时，旧调度器误把其根任务作为普通成员任务再次投递；现显式跳过每个根任务。旧全局 member 状态检查还会把所属团队的暂停传播为该 Native Agent 在另一团队的能力限制；现检查只作用于目标团队，所属旧团队仍保持暂停，新的独立关系可以正常工作。

## 2026-10-13：角色与标准 Agent 分层校正

按 ADR 0005 统一为 Orchestrator、Worker 两类职责角色。Allocator 的资源选择与分配职责归入 Orchestrator；研究、核验等用名称、instructions、skills 表达。标准 DSH Agent 仍是共同执行实现，角色不参与权限、验收权或生命周期分支。

委派的 profile 一次携带名称、角色、职责、原生 preset、模型与技能；随成员持久化，并用于创建和冷恢复。原生系统提示组合职责，已注入的宿主技能 registry 按目标 Agent 作用域解析技能。复用成员保留配置；更新任务不会静默重配成员。未声明配置使用正常默认值，未增加旧执行机制或兼容路径。

界面分别展示名称、角色与任务，颜色和图标对应职责；主会话/成员保留为归属和导航概念。节点详情可核对职责及创建配置，实际工具、模型和后续设置仍以原生会话为准。现有 schema 8 的可选配置字段不要求删除会话或换数据目录。
